# 3 个 awesome 清单 PR 文本片段

> 用法与 4.1 相同:fork 仓库 → 在指定分类加一行 → 跨仓库 PR(base 选原仓库 master ← compare 自己的 fork)。
> 每个清单的条目都是英文,保持一行格式。

---

## 1. LiteDevelopers/awesome-minecraft(首选,145★ 活跃)

- **仓库**:`github.com/LiteDevelopers/awesome-minecraft`
- **分类**:`Software → Tools(Miscellaneous tools)`(已收 Blockbench 等)
- **要加的行**:

```
- [CircleGen](https://pixelcircle.online) - Free Minecraft circle generator with block-by-block pixel blueprints in 11 languages.
```

- **PR 标题**:`Add CircleGen to Tools (Miscellaneous tools)`
- **PR 描述**:
  > Adds CircleGen, a free and open-source (MIT) web-based Minecraft circle generator. It produces block-by-block blueprints for circles, ovals, spheres, domes, arcs, toruses and ellipsoids, in 11 languages, with PNG/SVG export and /setblock output. Fits the existing Miscellaneous tools category alongside Blockbench.
- **注意**:仓库合并较慢(现积压 4 个 PR),提交后耐心等,2-3 个月后可礼貌跟进。
